# Thara in a browser

The built files of the web version of Thara (ثراء), served by GitHub Pages.
It is the same app as the phone's, compiled for the browser: sign in to your
Thara account and the phone and the browser show one wallet.

Nothing here is edited by hand: every file but this one comes from a build of
the app (`tool\build-web.ps1`, then `tool\publish-web.ps1`).

About the app, and its privacy policy: https://dvahasan.github.io/thara-site/
